# OPC Monitor

Система мониторинга OPC UA серверов с веб-интерфейсом, оповещениями и аналитикой.

## 🚀 Быстрый старт

### Требования
- Windows 10/11 + Docker Desktop + Minikube
- Или Linux/MacOS с Docker и Minikube

### Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-repo/opc-monitor.git
cd opc-monitor

# 2. Создать .env из примера
copy .env.example .env
# Отредактировать .env (пароли, настройки)

# 3. Запустить
start.bat
